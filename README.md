# 🚲 Bicycle Design Using SOLIDWORKS

> **3D Mechanical Design Project | Mechatronics Engineering**

This repository contains the complete 3D design, engineering drawings, and technical report for a bicycle modeled in SOLIDWORKS. It demonstrates practical application of CAD modeling, assembly constraints, and technical documentation standards.

---

## 🎓 Project Information

- **Author:** Jameel Faiz Bokaish
- **University:** Sana'a University – Faculty of Engineering
- **Department:** Mechatronics Department
- **Course:** Engineering Drawing
- **Academic Year:** 2023–2024
- **Completion Date:** June 2024

---

## 🎯 Project Objectives

- Design and model a full-scale bicycle using **SOLIDWORKS**.
- Apply advanced **CAD modeling concepts** (sketching, features, surfacing).
- Create detailed **engineering drawings** with proper dimensions and annotations.
- Assemble components using **mates and constraints** to verify fit and function.
- Document the design process in a comprehensive technical report.

---

## 📂 Repository Structure

| Folder | Description |
| :--- | :--- |
| `3DModel/` | Original SOLIDWORKS part (`.sldprt`) and assembly (`.sldasm`) files |
| `Drawing/` | 2D technical drawings (`.slddrw`) with dimensions and tolerances |
| `Report/` | Full project report (PDF) detailing design methodology and analysis |
