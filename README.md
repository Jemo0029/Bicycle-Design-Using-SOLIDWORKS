# Bicycle-Design-Using-SOLIDWORKS
3D Bicycle Design and Modeling Using SOLIDWORKS
Bicycle Design and Modeling Using SOLIDWORKS

Project Overview

This project presents the design and 3D modeling of a bicycle using SOLIDWORKS.

The project was completed as part of the Engineering Drawing course at the Faculty of Engineering, Mechatronics Department, Sana'a University.

Project Information

- Project Title: Design and Modeling of a Bicycle
- Software: SOLIDWORKS
- Department: Mechatronics Department
- Faculty: Faculty of Engineering
- University: Sana'a University
- Academic Year: 2023–2024
- Completion Date: June 2024

Project Objectives

- Design and model a bicycle using SOLIDWORKS.
- Apply CAD modeling concepts.
- Develop engineering drawing skills.
- Gain practical experience in 3D mechanical design.
